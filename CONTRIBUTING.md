# Contributing

Contribute to the canonical policy file under `regions/<region>/policies/<id>/`. Never assert an executable requirement from a source summary. Include exact primary document links and original language, effective dates, clause references, scope, ambiguity IDs, reviewer and alternative interpretations. Preserve `SOURCE.md`, `INTERPRETATION.md`, `RELATED.md`, and `rule.rulespec.yaml`. Record original documents as verified or pending; preserve copyright restrictions. Reviewed translations must be distinguished from editorial drafts.

All UI pull requests: record **Keyboard tested: yes/no**, browsers, assistive technology, RTL status, and unresolved barriers. Run validators and build. Unverified legal changes require visible review status.
