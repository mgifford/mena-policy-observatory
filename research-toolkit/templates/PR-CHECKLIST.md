# PR acceptance checklist

- [ ] Feature branch, no direct main modifications
- [ ] Baseline commit and diff recorded
- [ ] Every new legal claim has an official source and exact locator
- [ ] Source artifact authenticated or openly marked candidate
- [ ] Legal-effect and normative claims human reviewed if published
- [ ] Original text and editorial translation separated
- [ ] Unknown not silently converted to false / no law
- [ ] Rules do not silently ignore discretion or unresolved critical ambiguity
- [ ] Axiom compiled/tested only with exact engine pin and proof artifacts
- [ ] Existing `framework/validate.py` and unit tests run or reason not run
- [ ] Build, HTML lint and generated output check run or reason not run
- [ ] Accessibility Playwright + axe tested in both languages or reason not run
- [ ] Keyboard tested: yes / no (manual)
- [ ] Native Arabic and screen reader review state disclosed
- [ ] No sensitive personal case information committed
- [ ] Changes/removals and reasons, rollback and reviewers documented
- [ ] PR remains unmerged pending review
