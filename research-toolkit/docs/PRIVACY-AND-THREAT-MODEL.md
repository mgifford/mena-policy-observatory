# Safety, ethics, privacy and rights-sensitive research

Use only public institutional sources by default. Do not ingest personal case histories, migration records, reproductive health data, surveillance targets, protestor details or identities from case databases into git. Public availability does not establish safe reuse.

Before source/case integration ask:
- Are named individuals necessary to the research question?
- Could cross-linkage reidentify, target or stigmatize anyone?
- Does source licensing and applicable law permit reuse and redistribution?
- Would external hosted model access expose sensitive information?
- How would affected people request a correction/removal given immutable Git history and downstream forks?
- Are claims allegations, reported events, legal charges or adjudicated outcomes?

Use case-level aggregated counts only where methodology supports them, without comparing countries using raw counts. Keep source URLs outside git for embargoed/high-risk data. Threat model model providers, repository collaborators, indexing, browser analytics and archival mirrors. The default publication policy is **no individual-level sensitive case data**.
